### Project Architecture Recap

* **Stage 2 (Local Edge Correlation):** Chronological timeline correlation and risk assessment to filter false positives before heavy transformer processing.

### 1. Dataset Blueprint & Preparation Pipeline

#### XGBoost (Telemetry & Anomaly Triage)
* **Dataset:** **CICIDS2017** (Canadian Institute for Cybersecurity). It provides realistic background traffic and common attack vectors with 78 extracted features.
* **Preparation:** Clean NaN/Infinity values and apply `StandardScaler` normalization on Google Colab. 
* **Simulating Zero-Day Injections:** We will use an isolated holdout strategy. We will train XGBoost on common attacks but explicitly remove an entire attack class (e.g., "Botnet") from the training set. During the live demo, injecting a "Botnet" row via the Log Replay script will trigger the novelty anomaly threshold, kicking off the federated learning round on cue.

#### SecureBERT (LoRA Classification & Attack Labeling)
* **Dataset/Model:** Utilize the `ehsanaghaei/SecureBERT` base model. Fine-tune it using a custom Cyber Threat Intelligence (CTI) dataset mapping network anomaly signatures to specific attack classes.
* **Preparation:** Tokenize inputs using `RobertaTokenizerFast`. The base model weights will remain completely frozen, computing gradients only for the attached PEFT LoRA matrices.

#### Local RAG Store (Knowledge & Reasoning)
* **Dataset:** The official **MITRE ATT&CK Enterprise Matrix** in STIX JSON format.
* **Preparation:** Use the `stix2` Python library to parse the STIX JSON, extracting Tactics, Techniques, and mitigation procedures. Chunk and embed using a lightweight embedding model (e.g., `all-MiniLM-L6-v2`), and load into a local **ChromaDB** instance. Schema a mock "Historical Incident" JSON format to inject private organizational logs into the same ChromaDB instance.

### 2. Foundational Step-by-Step Implementation Flow

1. **Data Ingestion & Baseline Training (Colab):** Download CICIDS2017, isolate the zero-day holdout set, train the XGBoost triage model, and export the `.pkl` files.
2. **RAG Knowledge Base Construction:** Download the MITRE STIX JSON, parse it with Python, and populate the local ChromaDB vector store.
3. **Local Edge Orchestration:** Wrap SecureBERT with Hugging Face PEFT LoRA. Design the zero-shot Llama-3 prompt schema to consume the RAG context and the SecureBERT classification.
4. **Federated Communication Setup:** Deploy the Flower server (`server.py`) on Google Colab. Implement the FLoRA heterogeneous rank aggregation algorithm. Establish the ngrok tunnel to expose the gRPC port.
5. **In-Memory Fusion & Routing:** Configure the edge client (`client.py`) to receive global FLoRA weights and execute `merge_and_unload()` for zero-latency inference. Route the final outputs through the local FastAPI endpoints.
6. **End-to-End Mock Testing:** Initialize the Flutter dashboard. Run the Log Replay script to fire the zero-day telemetry into FastAPI and validate the complete pipeline.
